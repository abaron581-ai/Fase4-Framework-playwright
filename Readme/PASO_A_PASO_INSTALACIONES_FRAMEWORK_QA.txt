Request timed out after 30000ms


============================================================
9. SEGUNDO INTENTO: SOLO CHROMIUM
============================================================

Se intentó instalar únicamente Chromium con:

npx.cmd playwright install chromium

La descarga volvió a fallar por timeout.


============================================================
10. AUMENTO DEL TIEMPO DE ESPERA DE DESCARGA
============================================================

Se configuró temporalmente un tiempo de espera mayor en PowerShell:

$Env:PLAYWRIGHT_DOWNLOAD_CONNECTION_TIMEOUT="120000"

Luego se intentó nuevamente:

npx.cmd playwright install chromium

El tiempo máximo pasó de 30 segundos a 120 segundos.

Sin embargo, la descarga volvió a fallar.

Conclusión:
El problema no estaba en Playwright ni en el proyecto, sino en el acceso
a la descarga del navegador desde la red/equipo.

12. CONFIGURACIÓN DE PLAYWRIGHT PARA USAR GOOGLE CHROME
============================================================

Se modificó:

playwright.config.ts

Dentro del bloque "projects" se configuró:

projects: [
  {
    name: 'Google Chrome',
    use: {
      ...devices['Desktop Chrome'],
      channel: 'chrome',
    },
  },
],

Objetivo:
Evitar depender del navegador Chromium descargado por Playwright y
utilizar el Google Chrome ya instalado en Windows.

15. CONFIGURACIÓN DE PLAYWRIGHT CODEGEN
============================================================

El primer intento fue:

npx.cmd playwright codegen https://www.saucedemo.com/

Falló porque Codegen intentó buscar Chromium administrado por
Playwright.

Se corrigió usando el Chrome local:

Con este comando se abrieron correctamente:

- Google Chrome
- Playwright Inspector

2. Node.js
3. npm (incluido con Node.js)
