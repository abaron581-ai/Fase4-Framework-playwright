============================================================
7. ABRIR EL ÚLTIMO REPORTE DE PLAYWRIGHT
============================================================

Ejecutar:

npx.cmd playwright show-report

Se abrirá en el navegador el reporte HTML de la última ejecución.

El reporte permite revisar:
- pruebas ejecutadas;
- pruebas aprobadas;
- pruebas fallidas;
- duración;
- navegador utilizado;
- comportamiento inestable (flaky);
- pruebas omitidas.


============================================================
8. ABRIR PLAYWRIGHT CODEGEN / INSPECTOR
============================================================

Como estamos usando Google Chrome local, usar:

npx.cmd playwright codegen --channel=chrome https://www.saucedemo.com/

Esto abre:
1. Google Chrome.
2. Playwright Inspector.

Codegen permite:
- grabar acciones;
- descubrir localizadores;
- generar código automáticamente.

Para detener Codegen:

Ctrl + C

IMPORTANTE:
Codegen registra prácticamente todo lo que haces, incluidos clics
innecesarios o errores al escribir. El código generado sirve como
ayuda, pero debe revisarse y limpiarse antes de incorporarlo al
framework.

============================================================
10. LOCALIZADORES UTILIZADOS
============================================================

Actualmente SauceDemo expone atributos útiles como:

[data-test="username"]
[data-test="password"]
[data-test="login-button"]
[data-test="error"]

Los localizadores permiten que Playwright encuentre elementos de la
interfaz.

Playwright también puede utilizar localizadores como:

getByRole(...)
getByLabel(...)
getByPlaceholder(...)
getByText(...)

No todas las aplicaciones usan "data-test".
La elección del localizador depende de cómo esté construida cada
interfaz.

Por lo tanto, para ejecutar esas pruebas actualmente SÍ se necesita
internet.

Más adelante podremos incluir una aplicación local o un entorno de
pruebas interno si necesitamos ejecutar pruebas completamente sin
conexión.


============================================================
12. SI EL PROYECTO SE COPIA A OTRO EQUIPO
============================================================

En otro computador se necesitará, como mínimo:

1. Instalar Node.js.
2. Instalar Git.
3. Instalar VS Code.
4. Descargar o clonar el repositorio del framework.
5. Abrir la carpeta del proyecto.
6. Ejecutar:

   npm install

Esto reconstruye node_modules utilizando package.json y
package-lock.json.

7. Tener disponible un navegador compatible.

Si se mantiene la configuración actual:

channel: 'chrome'

también se deberá tener Google Chrome instalado.
